# 재활치료부 연차·휴가 관리 시스템

`index.html` 파일 하나로 동작합니다. 설치할 프로그램이 없고, 파일을 더블클릭하면 브라우저에서 열립니다.

---

## 1. 쓰는 순서

1. `index.html` 더블클릭 → 브라우저에서 열림
2. **[1. 엑셀 자료 불러오기]** 에서 `연차관리 자료요청서.xlsx` 선택
3. **[데이터 검증 · 설정]** 탭에서
   - **잔액 기준일** 확인 (엑셀 제목의 "9/16 기준"을 자동으로 읽어 채웁니다)
   - **확인이 필요한 항목** 목록 확인 (아래 4번 참고)
4. **[달력]** 탭에서 날짜를 눌러 휴가 등록
5. **주 1회 [💾 엑셀 백업 내려받기]** 클릭

> 등록한 휴가는 **이 컴퓨터의 이 브라우저**에 자동 저장됩니다.
> 브라우저 기록·사이트 데이터를 지우면 함께 사라지므로 백업이 필요합니다.
> 백업 파일을 다시 업로드하면 직원·연차현황·휴가내역·정책·설정이 **전부 복원**됩니다.

---

## 2. 엑셀 시트와 프로그램의 연결

| 시트 | 프로그램에서 쓰이는 곳 |
|---|---|
| ①직원명부 | 직원 목록, 소속(1층/2층/낮병동), 직종, 입사일, 써티/비써티 구분 |
| ②연차현황 | **부여·이월·사용·잔여의 기준값**, 월금·공휴일·장기 카운팅 시작값 |
| ④최소인력기준 | 동시휴가 상한 경고 (오전/오후 최소인원은 미입력 상태라 아직 못 씁니다) |
| ⑤경조사·특별휴가 | 정책 표시 (일수가 미입력이라 자동 적용은 아직 못 합니다) |
| ⑥공휴일·블랙아웃 | 병원 지정 휴무일, 휴가 제한일(달력에 보라색 테두리 + 등록 시 경고) |
| ⑦운영정책 | 정책 표시 (입사일 기준·이월 허용·반차 운영 등) |

- 시트 이름의 괄호 안 글자를 **소속**으로 씁니다. 예) `①직원명부(1층성인)` → `1층성인`
- 값은 칸 위치가 아니라 **헤더 글자**로 찾습니다. → 성인낮병동 시트처럼 사용/이월 순서가 달라도 정확히 읽습니다.
- `예시` 글자가 있는 안내용 행은 자동으로 건너뜁니다.

---

## 3. 계산 기준

**잔여 = (②부여 + ②이월 − ②사용) − 잔액 기준일 이후 이 시스템에 등록한 사용분**

- 시스템은 **②연차현황의 엑셀 값을 기준**으로 계산합니다. (⑦운영정책의 "입사일 기준" 방침과 별개로, 실제 대장 수치를 그대로 씁니다)
- 입사일로 계산한 **부여(자동)** 값도 표에 함께 보여주고, 엑셀 값과 다르면 **차이를 주황색으로 표시**합니다. 자동계산은 참고용입니다.
  - 자동계산식: 1년 미만 11일 / 1년 이상 `15 + (근속−1)÷2`(내림), 최대 25일
- 월금·공휴일연접·장기휴가 횟수 = **엑셀의 기준일까지 값 + 기준일 이후 시스템 계산값**
- 잔액 기준일 **이전** 날짜로 등록한 휴가는 엑셀 사용일수에 이미 들어있다고 보고 **차감하지 않습니다**(달력 표시용). 등록할 때 경고가 뜹니다.

---

## 4. 업로드한 자료에서 확인이 필요한 부분

프로그램은 값을 **임의로 고치지 않고 목록으로만** 알려줍니다. ([데이터 검증 · 설정] 탭)

| 내용 | 건수 |
|---|---|
| ①명부에 있으나 ②연차현황에 없는 직원 | 6명 (선윤수, 정민영, 최용민, 신수경, 유시은, 유형준) |
| ②연차현황에만 있는 이름 | 1명 (정민영B ← 명부의 "정민영"과 같은 사람인지 확인 필요) |
| 잔여일수가 (부여+이월−사용)과 안 맞는 행 | 5건 (서우진, 김진아, 차휘람, 김연서, 김주옥) |
| 엑셀 부여일수 ≠ 입사일 자동계산 | 61명 (대부분 입사 1년 미만의 월별 발생분 → 엑셀 값이 맞습니다) |
| 카운팅 열에 정수가 아닌 값 | 1건 (김희중 장기 = 0.1) |
| 써티/비써티 구분이 없어 동시휴가 상한을 못 거는 직원 | 1명 (선윤수) |
| ⑤경조사 일수 미입력 | 10종 전부 |
| ④오전/오후 최소인원 미입력 | 3개 그룹 |
| ⑥병원 휴무일·휴가 제한일 실데이터 | 0건 (예시 행만 있었음) |
| ③결재선 시트 | 파일에 없음 |

---

## 5. 아직 못 하는 것 (자료가 채워지면 가능)

- **시간대별 인력 부족 경고** — ④의 오전/오후 최소인원이 필요합니다.
- **경조사 일수 자동 적용** — ⑤의 일수가 필요합니다.
- **승인 결재선** — ③결재선 시트가 필요합니다. 현재는 관리자가 직접 등록하는 구조입니다.
- **직원 본인 로그인** — ⑦운영정책에서 "관리자만 사용"으로 정해져 있어 만들지 않았습니다.
- **여러 명 동시 사용** — 지금은 브라우저 저장 방식이라 한 대의 PC 기준입니다. 필요해지면 저장 부분만 서버로 바꾸면 됩니다.

## 6. 코드 구조 (index.html 안)

```
[1] 전역 상태          masterData(엑셀 자료) · leaveEvents(등록한 휴가) · settings(기준값)
[2] 공통 도구          날짜 변환, 숫자 읽기, 알림창
[3] 저장 · 불러오기    localStorage 자동 저장 / 복원 / 비우기
[4] 엑셀 읽기          시트 이름으로 구분 → 헤더 글자로 값 찾기 (①②④⑤⑥⑦ + 백업의 휴가내역·설정)
[5] 데이터 검증        고치지 않고 확인 목록만 생성
[6] 규칙 계산 엔진     잔여 / 월금 / 공휴일연접 / 장기휴가 / 동시휴가 상한 그룹 판정
[7] 화면 그리기        달력 · 직원별 현황표 · 검증 리포트 · 정책 표시
[8] 휴가 등록·수정·삭제 등록 전후 경고(잔여부족·기준일이전·블랙아웃·상한초과·한도초과)
[9] 엑셀 백업          원본과 같은 형식으로 저장 → 다시 업로드하면 완전 복원
[10] 시작             페이지 열 때 저장된 데이터 자동 복원
```

> 인터넷이 차단된 PC에서는 엑셀 읽기/쓰기 라이브러리(SheetJS, cdnjs)를 못 받아 업로드가 동작하지 않습니다.
> 그런 경우 `xlsx.full.min.js` 파일을 `index.html` 옆에 두고 `<script src="xlsx.full.min.js">` 로 바꾸면 됩니다.
